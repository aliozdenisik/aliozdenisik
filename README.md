## 🚀 Featured Projects

### 🏭 Takımsan — TRM Pricing Automation *(active)*
Real-time production data ingestion from 5 ANCA CNC machines via **OPC UA**; cycle-time prediction over 365 days of historical data (~46K cycles, ~112K operation records) using **per-operation XGBoost / CatBoost** models. SHAP for explainability, Optuna for HPO, FLAML for auto-retraining. Goal: automate 85% of the quoting process.
`asyncua` · `OPC UA` · `XGBoost` · `CatBoost` · `Optuna` · `SHAP` · `SQL Server`

### 🔍 [Clarus](https://github.com/aliozdenisik/Clarus)
A RAG system designed for **maximum retrieval accuracy on religious texts**. Combines dense semantic search with multi-agent LLM synthesis to deliver scholarly-quality comparative analysis across the Quran (8 Turkish translations) and the Bible (KJVA + Turkish).
`Python` · `TypeScript` · `RAG` · `Multi-agent`

### 📊 [Kelam Haritası](https://github.com/aliozdenisik/kelam-haritasi)
An **interactive D3.js visualization** of Prof. Dr. Caner Işık's Kelam corpus — mapping 700 years of Turkish Sufi poetic tradition as a network graph.
`D3.js` · `Data Visualization`

### 📧 [Email Sorter](https://github.com/aliozdenisik/email-sorter)
LLM-powered **automatic Gmail classifier**. Polls the inbox, evaluates subject + body with AI, and assigns the best-matching label.
`Python` · `Gmail API` · `LLM` · `Automation`

### ⚓ [MCDM Maritime Risk Assessment](https://github.com/aliozdenisik/MCDM-Based-Maritime-Vessel-Risk-Assessment)
An integrated risk-analysis framework for maritime vessels based on **multi-criteria decision making**. A decision-support tool for safety-management processes.
`Python` · `MCDM` · `Risk Analysis`

### 🎙️ Transcription Suite
A **Groq + WhisperX**-based web app for Turkish audio transcription, with academic PDF export and long-audio chunking.
`Python` · `Whisper` · `Groq`
